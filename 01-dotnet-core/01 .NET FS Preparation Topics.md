

# 🚀 .NET Full Stack Interview Preparation

This repository contains a structured preparation plan for a **Senior Software Engineer (.NET Full Stack)** role with **5+ years of experience**, focusing on real-world problem-solving, system design, and production-grade development.

---

## 📌 Objective

To build deep expertise across:

* Backend development with **.NET Core**
* Frontend development with **React**
* Scalable system design
* Clean architecture & coding best practices
* Real-world enterprise application scenarios

---

## 🧠 1. .NET Core Fundamentals

### Topics to Cover:

* .NET Core vs .NET Framework
* CLR, JIT, Garbage Collection (Gen 0,1,2)
* Middleware Pipeline
* Dependency Injection (DI Internals)
* Configuration & Options Pattern
* Logging (Serilog, ILogger)

### Deep Dive:

* Service Lifetimes (Scoped, Singleton, Transient)
* Middleware vs Filters
* Exception handling strategies

---

## 🌐 2. ASP.NET Core (Web API)

### Core Concepts:

* REST API Design Principles
* Routing (Attribute vs Conventional)
* Model Binding & Validation
* Filters (Action, Exception, Authorization)

### Security:

* JWT Authentication (Flow + Implementation)
* OAuth Basics
* CORS Handling
* Rate Limiting

### Practical:

* Build production-ready APIs
* Global error handling middleware

---

## ⚛️ 3. Frontend - React

### Core Topics:

* Functional Components
* Hooks (useState, useEffect, useMemo, useCallback)
* Component Lifecycle
* Controlled vs Uncontrolled Components

### Advanced:

* State Management (Context API / Redux)
* API Integration (Axios / Fetch)
* Performance Optimization
* Component Reusability

### EF Core:

### SQL:

* Joins (Inner, Left, Right)
* Group By & Having
* Window Functions (ROW_NUMBER, RANK)
