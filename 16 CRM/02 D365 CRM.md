## 1. Design a CRM to ERP Integration

### Question

A customer creates an Order in Dynamics CRM. It should be sent to SAP immediately. How would you design it?

### Expected Answer

```
User
   │
   ▼
Dynamics CRM
   │
Post Operation Plugin
   │
Azure Service Bus Queue
   │
Azure Function
   │
SAP API
   │
Application Insights
```

Why?

* User doesn't wait
* Queue provides retry
* Azure Function scales automatically
* Dead Letter Queue handles failures
* Easy monitoring

**Follow-up**

Why not call SAP directly?

Because

* SAP may take 20 seconds
* CRM timeout
* User experience degrades
* Plugin transaction becomes long-running
